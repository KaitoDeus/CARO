Hướng Dẫn Cài Đặt

Bản Cài Đặt (Setup)

Dành cho người dùng muốn cài đặt ổn định vào hệ thống.

  • B1. Tải file GameCaro_Setup_v0.0.x.exe từ link tải.
  • B2. Chạy file Setup, nhấn Next liên tục để cài đặt.
  • B3. Game sẽ xuất hiện ngoài Desktop và Start Menu.

Bản Portable (Chạy Ngay)

Dành cho USB hoặc chơi nhanh không cần cài đặt.

  • B1. Tải file nén GameCaro_Portable_v0.0.x.zip hoặc file exe chạy liền.
  • B2. Giải nén file zip (nếu có) vào một thư mục.
  • B3. Chạy file GameCaro.exe để chơi ngay lập tức.

Hướng Dẫn Chơi

1

Chuẩn Bị

Tải game về và giải nén. Chạy file GameCaro.exe. Hãy đảm bảo cả 2 máy tính cùng kết nối vào một mạng WiFi nếu chơi LAN.

2

Kết Nối (LAN)

Máy Chủ (Host): Nhập IP của mình -> Bấm nút 'LAN' để tạo phòng.

Người Chơi (Client): Nhập IP của Máy Chủ -> Bấm nút 'LAN' để vào phòng.

3

Luật Chơi

Người chơi lần lượt đánh O hoặc X. Người nào tạo được 5 quân liên tiếp (ngang, dọc, chéo) trước sẽ chiến thắng.

4

Phím Tắt

  • Ctrl + N: Ván mới
  • Ctrl + Z: Đi lại (Undo)
  • Ctrl + Y: Đi tiếp (Redo)
  • Esc: Thoát game
